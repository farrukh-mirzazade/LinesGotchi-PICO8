# Lines System

## Baseline

The Lines mode should be simple and close to classic Color Lines.

Open decisions:

- Board size.
- Number of colors.
- Required line length.
- Whether diagonal lines count.
- Number of new balls after a non-scoring move.

## Recommended MVP Defaults

- Board: `7x7` or `8x8`.
- Colors: `5`.
- Clear line length: `5`.
- Lines: horizontal, vertical, and diagonal.
- Input: keyboard/gamepad first.
